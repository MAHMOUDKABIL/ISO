# ديوان المُراجِع 🖋
**إعداد: د. محمود الباز قابيل — محاسب ومراجع قانوني**

منصة تدقيق مالي احترافية تعمل بـ Vanilla JS و CSS خالص، مباشرةً في المتصفح.

## الأدوات
| الصفحة | الأداة | المنهجية |
|---|---|---|
| scanner.html | الفحص الذكي الموحد | Isolation Forest + Z-Score + IQR (معًا) |
| benford.html | قانون بنفور | Benford + مؤشر MAD |
| ratios.html | النسب المالية | تحليل فترتين مقارنتين مع تقييم مهني |
| duplicates.html | كشف التكرارات | تكرارات + تطابقات + فجوات تسلسل |
| sampling.html | عيّنات التدقيق | عشوائي / منتظم / MUS |
