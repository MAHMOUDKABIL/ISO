# مِرْصاد الفواتير — منصة الفحص غير المُشرف للفواتير الإلكترونية

منصة بحثية تستقبل صادرات منظومة الفاتورة الإلكترونية أو الـERP (شيت Excel أو JSON)،
وتعزل الفواتير المشتبه فيها بإجماع **ثلاث خوارزميات تعلّم غير مُشرف** مكتوبة من الصفر
داخل المتصفح (غابة العزل + K-Means++ + Autoencoder)، مع تفسير **XAI** لكل قرار عزل
بصياغة مهنية موجهة للمراجع، وسحب **عينة عشوائية 5٪** وفق معيار المراجعة المصرى (530)،
وتصدير تقريري **Word وExcel** بترتيب الملف المرفوع.

> ⚠️ إعداد الباحث **محمود الباز فوزي قابيل** — لأغراض البحث العلمي فقط · ☎ 0106777481

## المزايا
- فحص محلي 100٪ داخل المتصفح — لا تُرفع البيانات لأي خادم.
- 13 سمة مشتقة: نسبة الضريبة مقابل 14٪، فرق التسوية، فجوة الإصدار/التقديم، تكرار الأرقام، التقريب…
- قواعد قطعية + نماذج إحصائية، ونسبة عزل قابلة للضبط (Contamination).
- بذرة توليد ثابتة تجعل العينة العشوائية قابلة لإعادة الإجراء وتوثيقها بأوراق المراجعة.
- بطاقة تحليل XAI لكل فاتورة: درجات المحركات الثلاثة، الأسباب، توصية، وتعليق مراجع يُضمَّن بالتصدير.
- ملف تجريبي مدمج (132 فاتورة، 11 حالة شاذة محقونة) للتجربة الفورية.

## التشغيل والنشر على GitHub Pages
1. أنشئ مستودعًا جديدًا وارفع ملفات المشروع بنفس الهيكل.
2. من **Settings → Pages** اختر الفرع `main` والمجلد الجذر `/` ثم Save.
3. افتح `https://<username>.github.io/<repo>/` — أو simply افتح `index.html` محليًا.

## صيغة الملف المقبولة
الصف الأول: مسلسل · تفاصيل · نوع المستند · نسخة المستند · الحالة (Valid/Invalid/Cancelled) ·
تاريخ الإصدار · تاريخ التقديم (dd/mm/yyyy) · عملة الفاتورة (EGP) · قيمة الفاتورة ·
ضريبة القيمة المضافة · إجمالى الفاتورة · الرقم الداخلى · الرقم الإلكترونى.

اختياريًا، تحقق من القالب قبل الرفع:
```bash
pip install openpyxl
python tools/verify_columns.py invoices.xlsx
```

## لماذا JavaScript وليس Python في الخادم؟
GitHub Pages استضافة ثابتة بلا خوادم، لذا بُنيت المحركات الثلاثة بجافاسكربت خالصة دون أي
مكتبات تعلّم آلة، بينما تُرفَق بايثون كأداة مساعدة اختيارية للتحقق من القالب.
