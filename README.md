# العزل الذكي - منصة فحص الفواتير الالكترونية

منصة بحثية تستقبل ملفات الفواتير الالكترونية (Excel او JSON) من منظومة الفاتورة
الالكترونية او نظام ERP، وتعزل الفواتير المشكوك فيها باستخدام ثلاث طرق ذكية
تعمل معا بدون اي بيانات سابقة (غابة العزل + التجميع + الشبكة العصبية)،
مع كتابة سبب واضح لكل فاتورة معزولة، وسحب عينة عشوائية 5% حسب معيار
المراجعة المصري رقم 530، واخراج تقارير Word و Excel.

> اعداد الباحث: محمود الباز فوزي قابيل - اغراض البحث العلمي فقط - هاتف 0106777481

## ما تقدمه المنصة
- 4 خطوات فقط: رفع الملف - تشغيل الفحص - مراجعة النتائج - اخراج التقرير
- لوحة مؤشرات: عدد الفواتير، المعزولة، الخطورة العالية والمتوسطة، العينة، اتفاق الطرق
- نظرة عامة: توزيع درجات الشك، القيمة مقابل الضريبة، تحليل قانون بنفورد،
  ملخص القيم (متوسط ووسيط واكبر واصغر)، اعلى 10 فواتير
- اختبارات سريعة مثل برامج المراجعة الكبيرة: خطأ في الحساب، نسبة ضريبة مخالفة،
  ارقام مكررة، فرق تواريخ، حالة غير سارية - والضغط على اي اختبار يعرض حالاته
- مستويات خطورة (عالية / متوسطة / منخفضة) لكل فاتورة
- حالة مراجعة لكل فاتورة (جديدة / قيد المراجعة / تمت المراجعة) وتعليق للمراجع
- سجل تدقيق يسجل كل خطوة، ويصدر ضمن ملف Excel
- تصدير Word و Excel و طباعة و JSON - بنفس ترتيب الملف الاصلي
- ملف تجريبي جاهز (132 فاتورة فيها 11 حالة غير طبيعية) للتجربة الفورية
- كل الفحص يتم داخل جهازك، لا يرسل اي ملف لاي مكان

## التشغيل والنشر على GitHub
1. ضع الملفات الخمسة في مجلد واحد (index.html و style.css و ml.js و app.js و README.md)
2. ارفعها الى مستودع GitHub (سحب وافلات من صفحة المستودع)
3. من Settings ثم Pages اختر الفرع main واضغط Save
4. افتح الرابط الذي يظهر لك

## شكل الملف المطلوب
الصف الاول يحتوي على: مسلسل، تفاصيل، نوع المستند، نسخة المستند، الحالة
(Valid / Invalid / Cancelled)، تاريخ الاصدار، تاريخ التقديم (مثل 26/11/2025)،
عملة الفاتورة (EGP)، قيمة الفاتورة، ضريبة القيمة المضافة، اجمالي الفاتورة،
الرقم الداخلي، الرقم الالكتروني.

## تنبيه
النتائج مؤشرات تساعد المراجع في اختيار العينة التي تستحق وقته،
والقرار النهائي دائما للمراجع البشري. المنصة اصدار بحثي وتستخدم
على مسؤولية المستخدم.
